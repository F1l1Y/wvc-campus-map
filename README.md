# West Valley Campus Map

Interactive map of the West Valley College campus (Saratoga, CA), built by the AI Builders Club.
Static site: Leaflet + OpenStreetMap tiles + `campus.geojson`. No backend, no keys, no analytics.

- Building footprints: © OpenStreetMap contributors, ODbL 1.0
- Building codes: West Valley College campus map (westvalley.edu), verified codes only
- Club-built, not an official college site. No college marks are used.

Edit `campus.geojson` to fix names or codes. The ABC lab marker is in `app.js` (`ABC_LAB`); set
`verified: true` once the location is confirmed on site.
